# Запись на тренировки: бот и мини-приложение Telegram

CRM для тренеров по фигурному катанию и их спортсменов.

**Тренер:**
- задаёт рабочие часы по каткам и сетку сеансов на каждом катке;
- подтверждает заявки;
- отмечает занятия и элементы спортсменов;
- делает рассылки и смотрит статистику.

**Спортсмен или родитель:**
- записывается по ссылке или QR-коду тренера;
- подтверждает, что придёт;
- получает напоминания;
- собирает ачивки.

| Часть | Где работает | Что делает |
|---|---|---|
| `webapp/` | GitHub Pages (бесплатно) | Мини-приложение: все экраны, светлая и тёмная тема берётся из Telegram |
| `supabase/functions/api` | Supabase Edge Functions | API мини-приложения, проверяет подпись Telegram |
| `supabase/functions/bot` | Supabase Edge Functions | Вебхук бота: `/start` по ссылке тренера и кнопки «Приду», «Подтвердить» и т. д. |
| `supabase/functions/cron` | Supabase Edge Functions, раз в 5 минут | Напоминания, сводка в 08:00, запрос подтверждения недели в вс 18:00, заморозка в пн 12:00 |
| `supabase/migrations` | Supabase Postgres | Таблицы. Доступ к базе из браузера закрыт, работать с ней могут только функции |

Время везде считается по Минску (UTC+3).

## Запуск: один раз, около 20 минут

### 1. Бот в Telegram
1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot` и задайте имя и username бота.
2. Сохраните **токен** (вида `123456:ABC…`) и **username** бота без `@`.

### 2. Проект в Supabase
1. Зарегистрируйтесь на [supabase.com](https://supabase.com) и нажмите **New project**. Хватит бесплатного плана.
2. Придумайте и сохраните **пароль базы данных**.
3. Когда проект создастся, откройте **Project Settings → General** и скопируйте **Project ID**. Это `PROJECT_REF`, он же часть адреса `https://PROJECT_REF.supabase.co`.
4. Создайте токен доступа: [supabase.com/dashboard/account/tokens](https://supabase.com/dashboard/account/tokens) → **Generate new token**.

### 3. Настройки репозитория на GitHub
1. **Settings → Pages → Build and deployment → Source: GitHub Actions.**
   Бесплатно GitHub Pages работает только с **публичным** репозиторием. Это безопасно: все токены лежат в секретах GitHub, а не в коде.
2. **Settings → Secrets and variables → Actions → вкладка Secrets → New repository secret.** Добавьте:

   | Имя | Значение |
   |---|---|
   | `SUPABASE_ACCESS_TOKEN` | токен из шага 2.4 |
   | `SUPABASE_DB_PASSWORD` | пароль базы из шага 2.2 |
   | `TELEGRAM_BOT_TOKEN` | токен бота из шага 1 |
   | `CRON_SECRET` | любая длинная случайная строка, например 40 латинских букв и цифр |
   | `WEBHOOK_SECRET` | ещё одна случайная строка (только буквы, цифры, `_` и `-`) |

3. Там же, на вкладке **Variables → New repository variable**:

   | Имя | Значение |
   |---|---|
   | `SUPABASE_PROJECT_REF` | Project ID из шага 2.3 |
   | `BOT_USERNAME` | username бота без `@` |

4. Откройте вкладку **Actions** и запустите оба сценария кнопкой **Run workflow**, по порядку:
   1. **Backend → Supabase** — создаёт таблицы, разворачивает функции и подключает к ним бота.
   2. **Mini app → GitHub Pages** — публикует мини-приложение по адресу `https://<ваш-логин>.github.io/coachapp/`.

   Дальше оба сценария запускаются сами при каждом изменении кода.

### 4. Расписание задач
1. Supabase → **SQL Editor** → **New query**.
2. Вставьте содержимое файла [`supabase/cron.sql`](supabase/cron.sql). Замените в нём `PROJECT_REF` и `CRON_SECRET` на свои значения.
3. Нажмите **Run**. Если появится ошибка про расширение, включите `pg_cron` и `pg_net` в **Database → Extensions** и запустите ещё раз.

### 5. Проверка
1. Откройте бота и отправьте `/start`. Внизу появится кнопка **«Запись»**.
2. Войдите как **Тренер**: **Профиль → Настройки → Рабочие часы и катки**, отметьте время и нажмите **Сохранить**.
3. **Профиль → Ссылка и QR-код**: отправьте ссылку со второго аккаунта Telegram и запишитесь как спортсмен.

## Как это устроено
- **Вход** — только через Telegram. Каждый запрос мини-приложения подписан Telegram (`initData`), и функция `api` проверяет подпись токеном бота.
- **Подтверждение заявок** — в настройках тренера, три режима: все заявки, только новые спортсмены, автоматически.
- **Подтверждение недели.** В воскресенье в 18:00 бот просит тренера подтвердить следующую неделю. Если до понедельника 12:00 этого не сделать, спортсмены при записи видят предупреждение «возможны изменения». После подтверждения создаются постоянные записи.
- **Постоянная запись.** Если спортсмен 3 недели подряд ходит в одно и то же время, приложение предлагает бронировать это время автоматически. После двух отказов предложение больше не появляется.
- **Поздние отмены.** После 3 поздних отмен за месяц бот предлагает тренеру отправить предупреждение. Потом тренер может закрыть спортсмену запись к себе.
- **Мини-группы** — до 3 человек. Скидка каждому: вдвоём −10%, втроём −20%. Цена указывается за час и не меняется, если сеанс короче часа.
- **Ачивки:**
  - огонёк за 10, 25, 50 и 100 занятий;
  - «Ранняя пташка» — занятие до 7:30;
  - «Ночной лёд» — занятие с 22:00;
  - «Хэллоуин» — 31 октября;
  - «Новогодний лёд» — 31 декабря.
- **Календарь.** В профиле есть ссылка-подписка `.ics`: занятия сами появляются в календаре телефона.

## Ограничения бесплатного плана Supabase
Бесплатный проект засыпает, если неделю к нему никто не обращается. Задача по расписанию обращается к нему каждые 5 минут, это должно держать проект активным, но гарантии нет. Если проект всё же уснул, откройте его в панели Supabase и нажмите **Restore**. Для постоянной работы позже можно перейти на платный план или свой сервер, код при этом менять не нужно.
